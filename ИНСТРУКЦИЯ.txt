ИНТЕРАКТИВНАЯ ПРАКТИЧЕСКАЯ РАБОТА «АЛГОРИТМЫ»

1. Откройте репозиторий algorithms-practical-work.
2. Нажмите Add file → Upload files.
3. Загрузите файл index.html из папки dist.
4. Нажмите Commit changes.
5. Перейдите Settings → Pages.
6. В разделе Build and deployment выберите:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
7. Нажмите Save.

QR-код ведёт на адрес:
https://adiletserikkazy2-max.github.io/algorithms-practical-work/

Студент вводит ФИО и группу, выполняет 10 заданий и получает оценку.
Каждое задание оценивается максимум в 10 баллов. Общий результат — 100 баллов.
В развёрнутых ответах учитывается смысл: за частично правильный ответ начисляется часть баллов.
Результат можно сохранить через кнопку «Печать или PDF».
